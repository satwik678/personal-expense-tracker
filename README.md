# Personal Expense Tracker

A simple Python program for recording daily expenses, calculating total spending, identifying the highest expense, and checking the user's budget.

## Features

* Record multiple expenses
* Calculate total spending
* Find the highest expense
* Compare spending with a monthly budget
* Display a formatted summary

## Technologies Used

* Python 3.14.6
* Visual Studio Code(VS Code)
* Git
* GitHub
* SSH (Secure Shell)

## Conclusion

This project demonstrates Python basics such as variables, functions, lists, dictionaries, loops, and conditional statements through a practical expense tracking application.
